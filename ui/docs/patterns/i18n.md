# i18n

Reference: `src/i18n/`.

- **Two languages:** English (`en`) and Traditional Chinese (`zh-Hant`). The choice is stored in `localStorage` (`language`); the first visit follows the browser (any `zh*` gets 繁體中文). Signed-in people change it on the Settings page; the login page and public setlist view keep `LanguageSwitch`. `<html lang>` follows.
- **Keys** are nested by feature (`songs.columns.title`) in `src/i18n/locales/en.json` and `zh-Hant.json`. Add every key to both files; `locales.test.ts` fails if they differ. `t()` is type-checked against the English file.
- **Interpolation:** `t('home.greeting', { name })`; never concatenate translated fragments.
- **Song content** (titles, lyrics, artists) is data, not UI text; never translate it.
- **Write the Chinese yourself or flag it:** if you can't produce a good 繁體中文 string, copy the English and say so in the PR so a native speaker can fix it.
