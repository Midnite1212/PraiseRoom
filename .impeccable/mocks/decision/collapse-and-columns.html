RIPPLE OUT · DESKTOP DETAILS

Collapse icon and column control

Three icons for moving the setlist between beside and above, and three ways to choose the number of lyric columns.

Setlist collapse icon

I1 · Sidebar panel

The familiar toggle (macOS, VS Code, Notion). Same icon in both states; the tooltip says what happens.

I2 · Layout switch

Shows where the list will go: a top band moves it above; a side column brings it back beside.

I3 · List with arrow

Literal: the list goes up; the reverse arrow brings it back down beside.

Column control

C1 · Column glyphs

An icon switch drawn as columns: auto, one, two. Tooltips name each one.

C2 · Labelled menu

A button that says what it is, "Columns: Auto", opening a small menu.

C3 · Inside the Aa menu (recommended)

Columns join text size and theme as a "Layout" row with glyphs and words. The top bar gets simpler.
