Visual language kit: mix and match

E4 colours · Overpass (lyrics 200, headings 300) · Source Code Pro. No 1px outlines. Each row is one component; each column a language. Pick per component, for example "toggle from C, rows from A, Up next from D".

  • A · Tonal: soft fills, a sliding thumb, gentle shadows, 12px corners.
  • B · Navy-anchored: solid dusty-navy header and bars, white type.
  • C · Swiss index: 4px corners, mono numbers lead (01, 02), solid accent bars mark "current".
  • D · Tide line: active states fill from the bottom like a water level; the Up next bar fills as the set progresses.
  • E · Ghost: nothing drawn; type weight, colour and a small dot show state.
