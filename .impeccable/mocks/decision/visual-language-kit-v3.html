Visual language kit v3: patterns from text-centric products

E4 colours · Overpass (lyrics 200, headings 300) · Source Code Pro. Each row is one component; each column a language. Pick per component, for example "toggle from C, rows from A, Up next from D".

  • F · Reader (Kindle, Readwise Reader, iA Writer, Substack): text first, a reading-progress line, underlined text toggles, small-caps section heads, a full-width bottom bar.
  • G · Lyrics focus (Apple Music, Spotify lyrics): the section in focus is full strength and the rest dims; chip controls; filled current song.
  • H · Docs (Linear, Vercel, Stripe docs): a subtle-fill list with a left accent bar, outlined 8px buttons with tiny shadows, keyboard hints in the Up next bar.
  • I · Scripture (YouVersion, ESV.org): songs as chapters, a numbered chapter grid for the list, a book-and-chapter navigator pill, line numbers on lyrics.
